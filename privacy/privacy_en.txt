Privacy Policy

Last updated: August 20, 2026

This Privacy Policy explains how the Lim application ("Application") and the LimServer server module process data.

Lim is designed to operate entirely within infrastructure controlled by its users. The Developer does not operate any cloud servers, relay servers, or messaging infrastructure. All communication takes place directly between the Application and a user-managed LimServer instance.

1. Definitions

Application
The Lim Android application installed on your Device.

LimServer
A Java server application installed and managed by the user or network administrator (for example, inside a Docker container on MikroTik CHR).

Device

2. Data Processing

The Developer does not control the servers used by the App and does not have technical access to your data.
The App processes only the information necessary to communicate with your LimServer.

Processed data may include:

Credentials
Username
Password
Display name
Server address

This information is entered manually by you.
Passwords are never stored or transmitted in cleartext.

Messages and Media Files

The App processes:

Text messages
Transferred files
Encrypted filenames

This data is exchanged only between your device and your LimServer.

Cryptographic Keys

The App generates a public/private key pair for each user.

The private and public keys are stored encrypted on your device.

The public key is uploaded to your LimServer so that other users can encrypt messages addressed to you.

The private key is encrypted with your password and uploaded to the server to enable syncing with your new device.

Server Certificate

The app can store an imported HTTPS server certificate (.crt), used to authenticate your LimServer.

The imported certificate is stored locally in encrypted form.

3. Data Storage
On your Android device

The app stores the following encrypted data:

Account settings;
Local message database;
Private encryption key;
Public encryption key;
Imported server certificate (if used).

Uploaded media files are stored in the app folder (/Android/data/com.safelogj.lim/files/) under unique names.

The app can store file URIs for quick access to uploaded files.

On LimServer

The server stores the following encrypted data:

Double hash of user passwords;
Private encryption key;
Messages;
File names;
Media files.

The server stores the following in cleartext:
Public encryption keys;
Chat metadata, user IDs and names;
Server settings, server certificate, and certificate password;

Uploaded media files are stored temporarily and are automatically deleted after the recipient has successfully uploaded them, or after 30 days if the file has not been downloaded.

4. Security

The application implements a multi-layered security system.

HTTPS

Data exchange between the application and LimServer is carried out via the HTTPS protocol.

Server Certificate Verification

The application supports importing your server's HTTPS certificate to verify the authenticity of your LimServer.

This allows you to securely use self-signed certificates without disabling certificate verification.

Password Protection

Passwords are hashed by the application before transmission.

The server re-hashes the received value before storing it.

The server never stores user passwords in cleartext.

End-to-end encryption

Messages, transferred files, and file names are encrypted on the sender's device using the recipient's public key.

Only the intended recipient can decrypt this information using their private key.

The server stores only encrypted content and cannot decrypt user messages or transferred files.

Voice Calls

Voice data is encrypted directly on the devices of the call participants using end-to-end encryption (E2EE).

LimServer acts exclusively as a UDP packet relay and has no technical means to decrypt the audio stream or record the conversation.

Voice data is not stored anywhere.

5. No External Services

Lim does not use:

Google Firebase
Firebase Cloud Messaging (FCM)
Google Analytics
Crashlytics
advertising networks
push notification providers
cloud messaging services
telemetry services

The Developer does not receive copies of user messages, files or any other communication data.

All communication occurs exclusively between the Application and your own LimServer.

6. Local Network Operation

The Android client is intended for private network environments.

The Application accepts connections only to private network IP addresses.

Connections to public Internet IP addresses are rejected by the client.

This restriction is intended to reduce the risk of accidental exposure of the Server to the public Internet.

You can further restrict the server's operation in the local network using CHR settings.

7. Background Operation

Because Lim does not rely on push notification services such as Firebase Cloud Messaging (FCM), Android limits how frequently the Application can check for new messages while running in the background.

When the Application is in the background, new messages are typically checked approximately every 15 minutes, depending on Android system restrictions.

When the Application is open, communication with the Server occurs immediately.

The Developer does not collect, receive, process or store:

passwords;
messages;
transferred files;
contacts;

device identifiers;
advertising identifiers;

crash reports;

The Application does not transmit user data to the Developer or third-party companies.

9. Server Administrator Responsibility

LimServer is installed and managed entirely by the user or network administrator.

The security of the server infrastructure, operating system, configuration files and certificates is the responsibility of the Server administrator.

The Developer is not responsible for the security of user-managed server installations.

10. Data Deletion
Account removal

Removing an account through the Application clears the local message database.

On LimServer, user data are anonymized, authentication data are removed and the account is disabled.

Application removal

Removing the Application deletes its local data, including:

encrypted settings;
local database;
imported certificates;
locally stored private encryption keys.

Files downloaded to folders outside the Application remain on your Device until you remove them manually.
