Политика конфиденциальности

Последнее обновление: 24 июля 2026 г.

Настоящая Политика конфиденциальности объясняет, как приложение Lim («Приложение») и серверный модуль LimServer обрабатывают данные.

Lim разработан для работы исключительно в инфраструктуре, контролируемой пользователями.
Разработчик не управляет облачными серверами, ретрансляционными серверами или инфраструктурой обмена сообщениями.
Вся связь осуществляется напрямую между Приложением и управляемым пользователем экземпляром LimServer.

1. Определения

Приложение
Приложение Lim для Android, установленное на вашем устройстве.

LimServer
Серверное приложение Java, установленное и управляемое пользователем или сетевым администратором (например, внутри контейнера Docker на MikroTik CHR).

2. Обработка данных

Разработчик не управляет серверами, используемыми Приложением, и не имеет технических возможностей доступа к вашим данным.
Приложение обрабатывает только информацию, необходимую для связи с вашим собственным LimServer.

Обрабатываемые данные могут включать:

Учетные данные
имя пользователя
пароль
отображаемое имя
адрес сервера

Эта информация вводится вами вручную.
Пароли никогда не хранятся и не передаются в открытом виде.

Сообщения и медиафайлы

Приложение обрабатывает:

текстовые сообщения
переданные файлы
зашифрованные имена файлов

Обмен этими данными происходит только между вашим устройством и вашим собственным LimServer.

Криптографические ключи

Приложение генерирует пару открытого/закрытого ключей для каждого пользователя.

Закрытый и открытый ключи хранится на вашем устройстве в зашифрованном виде.

Открытый ключ загружается на ваш LimServer, чтобы другие пользователи могли шифровать сообщения, адресованные вам.

Закрытый ключ зашифровывается вашим паролем и загружается на сервер для возможности синхронизации с вашим новым устройством.

Сертификат сервера

Приложение может хранить импортированный сертификат HTTPS-сервера (.crt), используемый для проверки подлинности вашего LimServer.

Импортированный сертификат хранится локально в зашифрованном виде.

3. Хранение данных
На вашем устройстве Android

Приложение хранит в зашифрованном виде:

настройки учетной записи;
локальную базу данных сообщений;
закрытый ключ шифрования;
открытый ключ шифрования;
импортированный сертификат сервера (если используется).

Загруженные медиафайлы хранятся в папке приложения (/Android/data/com.safelogj.lim/files/) под уникальными именами.

Приложение может хранить URI файлов для быстрого доступа к загруженным файлам.

На LimServer

Сервер хранит в зашифрованном виде:

двойной хэш пароля пользователей;
закрытый ключ шифрования;
сообщения;
имена файлов;
медиафайлы.

Сервер хранит в открытом виде:
открытые ключи шифрования;
метаданные чата, id и имена пользователей;
настройки сервера и сертификат сервера и пароль сертификата;

Загруженные медиафайлы хранятся временно и автоматически удаляются после успешной загрузки получателем или через 30 дней если файл не был скачан.

4. Безопасность

Приложение реализует многоуровневую систему безопасности.

HTTPS

Обмен данными между приложением и LimServer осуществляется по протоколу HTTPS.

Проверка сертификата сервера

Приложение поддерживает импорт HTTPS-сертификата вашего сервера для проверки подлинности вашего LimServer.

Это позволяет безопасно использовать самоподписанные сертификаты без отключения проверки сертификата.

Защита паролем

Пароли хешируются приложением перед передачей.

Сервер повторно хеширует полученное значение перед его сохранением.

Сервер никогда не хранит пароли пользователей в открытом виде.

Сквозное шифрование

Сообщения, передаваемые файлы и имена файлов шифруются на устройстве отправителя с использованием открытого ключа получателя.

Только предполагаемый получатель может расшифровать эту информацию с помощью своего закрытого ключа.

Сервер хранит только зашифрованное содержимое и не может расшифровать сообщения пользователей или передаваемые файлы.

5. Отсутствие внешних сервисов

Lim не использует:

Google Firebase
Firebase Cloud Messaging (FCM)
Google Analytics
Crashlytics
рекламные сети
поставщиков push-уведомлений
облачные сервисы обмена сообщениями
сервисы телеметрии

Разработчик не получает копии сообщений пользователей, файлов или любых других данных связи.

Вся связь осуществляется исключительно между Приложением и вашим собственным LimServer.

6. Работа в локальной сети

Клиент Android предназначен для работы в частных сетях.

Приложение принимает соединения только с IP-адресами частных сетей.

Соединения с общедоступными IP-адресами в Интернете отклоняются клиентом.

Это ограничение призвано снизить риск случайного доступа к серверу из общедоступного Интернета.

Вы можете дополнительно ограничить работу сервера в локальной сети настройками CHR

7. Работа в фоновом режиме

Поскольку Lim не использует сервисы push-уведомлений, такие как Firebase Cloud Messaging (FCM),
 Android ограничивает частоту проверки новых сообщений Приложением во время работы в фоновом режиме.

Когда приложение работает в фоновом режиме, проверка новых сообщений обычно происходит примерно каждые 15 минут,
 в зависимости от ограничений системы Android.

Когда приложение открыто, связь с сервером происходит немедленно.

8. Обмен информацией

Разработчик не собирает, не получает, не обрабатывает и не хранит:

имена пользователей;
пароли;
сообщения;
переданные файлы;
контакты;
IP-адреса;
идентификаторы устройств;
рекламные идентификаторы;
аналитические данные;
отчеты о сбоях;
статистику использования.

Приложение не передает данные пользователей разработчику или сторонним компаниям.

9. Ответственность администратора сервера

LimServer устанавливается и управляется исключительно пользователем или сетевым администратором.

За безопасность серверной инфраструктуры, операционной системы, конфигурационных файлов и сертификатов отвечает администратор сервера.

Разработчик не несет ответственности за безопасность серверных установок, управляемых пользователем.

10. Удаление данных
Удаление учетной записи

Удаление учетной записи через Приложение очищает локальную базу данных сообщений.

В LimServer данные пользователя анонимизируются, данные аутентификации удаляются, и учетная запись отключается.

Удаление приложения

Удаление Приложения удаляет его локальные данные, включая:

зашифрованные настройки;
локальную базу данных;
импортированные сертификаты;
локально хранящиеся закрытые ключи шифрования.

Файлы, загруженные в папки вне Приложения, остаются на вашем устройстве до тех пор, пока вы не удалите их вручную.
